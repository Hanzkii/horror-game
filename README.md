# Horror-Game

A 2D psychological horror platformer built with a custom browser-based game engine.

## Overview

- **Genre**: Psychological horror platformer
- **Engine**: Custom HTML5/Canvas engine
- **Art Style**: Dark, slightly pixelated horror aesthetic
- **Core Focus**: Eerie atmosphere driven by sound design, puzzles, and secret levels
